# DAVIS 프레임 탐색기

`~/davis_recordings`의 세션을 로컬에서 직접 읽는 비교 사이트입니다. 프레임과 이벤트 이미지를 좌우로 보여주고, `events.bin`에서 원하는 시간만큼 이벤트를 다시 합성하며, 방문자의 좋아요를 모읍니다.

## 설치 및 실행

Python 3.10 이상이 필요하며, 기존 테스트는 Python 3.13에서 확인했습니다.

```bash
git clone https://github.com/SungHwanYoo/davis-viewer.git
cd davis-viewer
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python server.py --recordings "$HOME/davis_recordings" --host 127.0.0.1 --port 8765
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 녹화 데이터는 별도로 준비하고 `--recordings`에 경로를 지정하세요. 이 저장소에는 촬영 이미지, 이벤트 원본, 계정·좋아요 DB, 로그가 포함되지 않습니다.

촬영 프로그램: [davis_event_recorder](https://github.com/SungHwanYoo/davis_event_recorder).

선택적으로 `cloudflared tunnel --url http://127.0.0.1:8765`로 공유할 수 있습니다. 터널 주소는 재시작할 때 바뀌며, 접속자는 녹화 이미지를 보고 공유 좋아요를 변경할 수 있습니다. 운영 배포 전에는 접속 범위를 별도로 설정하세요.

`start.command`와 `stop.command`는 원래 Mac 환경의 실행 보조 스크립트입니다. 다른 환경에서는 위 Python 명령을 사용하세요. macOS에서 스크립트를 사용하려면 `DAVIS_PYTHON`과 `DAVIS_RECORDINGS_DIR`을 본인 경로로 지정하세요.

## 사용법

- 왼쪽에서 세션을 선택합니다. 큰 화면의 왼쪽은 APS 프레임, 오른쪽은 대응하는 이벤트 이미지입니다.
- 아래 프레임 목록, 슬라이더, 번호 입력 또는 `←`·`→` 키로 이동합니다.
- **이벤트 누적 시간**을 0.01~3초로 조절하면 원본 `events.bin`에서 오른쪽 이미지를 다시 그립니다. **기록 이미지로 되돌리기**는 저장된 `events_vis` 이미지를 보여줍니다.
- **30-bin 보기**를 누르면 선택한 APS 프레임을 크게 유지한 채, `events.bin` 원본의 기준 시각 **이전 100 ms만** 30개 시간 구간으로 보여줍니다. 기준 시각과 그 이후 이벤트는 포함하지 않습니다. 넓은 화면에서는 6열 × 5행이며, 작은 화면에서는 칸을 읽기 쉽게 열 수가 줄어듭니다. 각 칸에 시간 범위, 전체 이벤트 수, ON/OFF 수를 표시합니다. 칸을 누르면 APS 옆에서 크게 비교할 수 있습니다. 큰 bin 이미지 위의 ←/→ 버튼이나 키보드 ↑/↓로 bin을 하나씩 넘깁니다. 키보드 ←/→는 기존처럼 프레임을 넘깁니다.
- 기준 시각은 `frame_timestamp_us + exposure_us/2`입니다. 옛 세션에 노출 시간이 없으면 프레임 시각을 사용하고 화면에 알립니다. 각 bin은 시작 시각을 포함하고 끝 시각을 제외하므로 경계 이벤트가 중복되지 않습니다. 30개 bin의 ON은 같은 빨강, OFF는 같은 파랑 밝기로 표시합니다.
- **30개 시간 bin** 제목 옆의 **접기**를 누르면 격자를 숨기고 큰 APS/bin 비교만 볼 수 있습니다. **펼치기**를 누르면 같은 격자가 다시 나타납니다.
- `♥` 또는 `L` 키로 프레임의 좋아요를 켜고 끕니다. 각 프레임의 좋아요는 0개 또는 1개이며, 다시 누르면 취소됩니다. 로그인하면 누가 좋아요를 켰는지 프레임 위에 표시됩니다. **좋아요만 보기**와 **좋아요순**으로 후보를 선별합니다.
- **현재 화면 공유**는 세션·프레임·보기 방식·선택한 bin 또는 이벤트 시간 설정이 담긴 링크를 복사합니다.

기록 당시의 `events_vis`에는 촬영 시 적용된 시각화 필터가 반영될 수 있습니다. 시간을 조절해 다시 그린 이미지는 필터 없는 원본 이벤트를 사용하므로 기본 이미지와 조금 다를 수 있습니다. 원본 `events.bin`, `frames`, `events_vis`는 수정하지 않습니다.

## 저장 위치 및 접속 범위

- 좋아요: 이 폴더의 `data/likes.sqlite3`에 저장됩니다.
- 계정은 관리자에게 받은 아이디와 비밀번호로 로그인합니다. 로그인 없이도 프레임의 좋아요를 켜거나 끌 수 있으며, 로그인한 상태에서 켜면 계정 이름이 표시됩니다. 이전 중복 표는 시작 시 프레임당 하나로 정리하고 나머지는 `likes_dedup_archive`에 보관합니다.
- 숨길 세션 ID는 `data/hidden_sessions.json` 배열에 저장합니다. 원본 녹화 파일은 그대로 두고 사이트 목록과 API 접근에서만 제외합니다. 설정 변경 후 서버를 다시 시작해야 합니다.
- 원본 `events.bin`을 다운로드하는 주소는 제공하지 않습니다. 서버가 필요한 구간만 읽어서 이미지로 전송합니다.
- 30-bin을 처음 열 때 해당 100 ms 원본 구간을 한 번 읽고 서버 메모리에 최근 프레임 12개의 결과를 보관합니다. 브라우저도 최근 8개 프레임의 bin 정보를 재사용합니다. 사이트 서버를 재시작하면 메모리 캐시는 비워집니다.

## 설정

필요하면 실행 전에 `DAVIS_RECORDINGS_DIR`, `DAVIS_VIEWER_PORT`, `DAVIS_PYTHON` 환경 변수를 지정할 수 있습니다. 기본값은 현재 컴퓨터의 녹화 폴더, 포트 8765, `davis_event_recorder`의 Python 가상환경입니다.

테스트: `python -m unittest discover -s tests -v`
